Point this at your own workflow

Wrap the decisions you already make, then render the page from the file it writes. No service to sign up for, no data leaves your machine. 

pip install "git+https://github.com/xxlya/evaljev"

# 1. record the decisions your workflow already makes
from evaljev import JevHTTPClient, Monitor, JsonlTraceStore
monitor = Monitor(JsonlTraceStore("traces.jsonl"))
response, trace = monitor.run(JevHTTPClient(), workflow_id="my-app",
                              node_id="classify_request", state=state,
                              questions=questions, policy=my_policy,
                              metadata={"request_id": request_id})  # ties the steps together
monitor.record_outcome(trace, outcome=what_happened, correct=True)  # when you find out

# 2. build this page
$ evaljev report traces.jsonl -o report.html     # one file, open it anywhere
$ evaljev serve traces.jsonl                     # or watch it live while traffic runs
