Watch your own workflow. Record the decisions you already make, then point the console at the file.

pip install "git+https://github.com/xxlya/evaljev"

from evaljev import JevHTTPClient, Monitor, JsonlTraceStore
monitor = Monitor(JsonlTraceStore("traces.jsonl"))
response, trace = monitor.run(JevHTTPClient(), workflow_id="my-app", node_id="classify",
                              state=state, questions=questions, policy=my_policy,
                              metadata={"request_id": request_id})

$ evaljev console traces.jsonl --open      # this screen
$ evaljev serve traces.jsonl               # the same screen, refreshing as traffic arrives
