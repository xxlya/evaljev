Point this at your own workflow. Three steps, about five minutes. Nothing leaves your machine and there is no service to sign up for.

  1. Wrap the client you already have. Your call sites do not change; every decision is appended to a file as it happens.
  2. Ship as usual. Each configuration you run on becomes a run this page can judge — you never tell it that you shipped.
  3. Audit. evaljev console traces.jsonl.
