The finding that justifies the whole library

Across 72 decisions there was exactly one wrong answer and exactly one paraphrase flip — and they are the same item. An inclusive-boundary policy question, asked two equivalent ways.

P(true) for two phrasings of one decision, 5 repeats each
Both phrasings mean the same thing, and the correct answer is yes for both.
Why this matters in production. There is no expected column on live traffic. But the paraphrase flip is observable without any label — and here it pointed at the one decision out of 72 that was wrong.

confidence is a margin, not a probability

The API reports c = (p_max − 1/k) / (1 − 1/k) — verified against 48 live answers to within the two-decimal reporting granularity. It carries no information beyond p_max and the option count k, which has a sharp consequence for anyone thresholding on it.

Three properties that are structural, not configurable

  • Nothing is ever applied. The cycle returns ranked proposals with their evidence; a human applies them.
  • The proposer never sees the holdout. Traces split deterministically by hashed trace_id, so a proposal cannot be laundered by re-rolling the split.
  • A candidate may not change the label set. That would move every downstream confidence threshold while looking like a wording fix.

The object everything is built on

One real DecisionTrace. Generic LLM observability records prompt and completion; this records the full distribution, the question schema, four independent version axes, and the downstream outcome — which is what makes the diffs above possible.

Reproduce it. The page reads docs/data.js, regenerated by python benchmarks/export_demo_data.py from the stored traces — so the demo cannot drift from the run that produced it. 

git clone https://github.com/fstandhartinger/jevbench.git /tmp/jevbench
python benchmarks/run_jevbench.py --data /tmp/jevbench/datasets/public/original.jsonl --cap 5.00
python benchmarks/export_demo_data.py

Your own workflow. pip install "git+https://github.com/xxlya/evaljev", record the decisions you already make, then evaljev report traces.jsonl -o report.html for the dashboard on your traffic.

Charts are hand-built SVG, no dependencies. Palette validated for colour-vision deficiency in both light and dark modes; every chart also ships a table or direct labels.
